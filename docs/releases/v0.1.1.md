# Terminal2 v0.1.1

タイトルバーの透明表示を解除し、AppKit 標準の背景を表示する。端末領域の透明度設定とは独立した変更で、タイトルバーと端末の境界を明確にした。

- リリース: [v0.1.1](https://github.com/fuba/terminal2/releases/tag/v0.1.1)
- ビルド番号: `20261031090402`
- 配布ファイル: `Terminal2-v0.1.1-macOS-arm64.zip`（2,076,214 bytes）
- 対応: Apple Silicon / macOS 26 以降
- SHA-256: `141d75bfb2a909b6abd65c462bfd5f454d1242939ae4ec1971381478d135610a`

## 検証

`scripts/test.sh` の29テスト成功。依存の固定・公開後24時間以上の監査を経て、`scripts/build.sh release` でビルドした。独立した設定の確認用アプリで、タイトルバーの標準背景を実画面で確認した。ユーザーの設定・接続先・起動中のセッションは変更していない。

ZIP を新規ディレクトリへ復元し、厳密なコード署名検査、実行ファイルのバイト一致、バージョン・bundle ID を確認した。設定・ログ・確認用の環境変数は同梱しない。SwiftTerm のライセンスを保持している。`scripts/install.sh` によりローカルのアプリも更新した。既存プロセスは維持し、再起動後に新しい外観になる。

変更範囲を直接レビューし、端末入力・通信・資格情報・依存の変更がないことを確認した。署名は ad hoc。Developer ID 署名・公証は行っていない。
