# Terminal2 v0.1.0

初回の GitHub Release。現在のビルド済みアプリを配布する。アプリのコード・依存・バージョン番号の変更は行っていない。

- リリース: [v0.1.0](https://github.com/fuba/terminal2/releases/tag/v0.1.0)
- アプリコード: `2eb50c60cf78a84e7d8c61cc28d843e10432f30d`
- アプリのバージョン: `0.1.0`
- ビルド番号: `20261030191413`
- 配布ファイル: `Terminal2-v0.1.0-macOS-arm64.zip`（2,076,215 bytes）
- 対応: Apple Silicon / macOS 26 以降
- SHA-256: `1bd2928ab326ba95049931463c7e4c1467e9ea187ddee8a340e5976da3ffb7e7`

## 内容

- AppKit / SwiftUI / Metal によるネイティブ端末、実 PTY、SSH、Tailscale。
- Cmd＋左右のタブ移動、キー割り当ての記録・変更・解除。
- 本体の外側に開く接続パネル、お気に入り、追加可能なシェル一覧。
- tmux 向け Option＋左右、画像表示・ファイル転送、日本語入力。
- macOS 標準フォントパネルと5種類の配色プリセット。

## 配布時の検証

アプリコードの29テスト成功を確認。配布 ZIP を新規ディレクトリに復元し、厳密なコード署名検査、元ビルドとの実行ファイルのバイト一致、バージョン・bundle ID・ライセンス同梱を確認した。ランタイムの設定やログは含まない。バイナリは arm64、最小 OS は26.0であり、Homebrew などのローカル dylib へのリンクはない。

署名は ad hoc。Developer ID 署名・公証は行っていない。Intel 向けバイナリは含まない。

`SHA256SUMS.txt` を同時に添付した。GitHub へ公開したアセットも再取得し、ローカルの SHA-256、復元後の署名、バイナリの一致を確認済み。

公開後、Mac のロック解除後に同じプログラムコードを独立設定で起動し、接続パネルと設定画面の最終表示も確認した。詳細は [追加確認](../native-ui-input.md#ロック解除後の追加確認) を参照。
