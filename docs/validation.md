## 正しさ・セキュリティの確認

変更を直接レビュー。SSH の宛先は引数として分離し、ホスト鍵検証は省略しない。鍵・パスワードをプロジェクトへ保存しない。転送は private な SSH socket と生成したリモートディレクトリを使い、リモートパスは生成・検査・引用してから入力する。クリップボード read、危険な URL scheme、リモート画像によるローカルファイル読み込みは許可しない。

外部コマンドにはタイムアウトと出力上限を設け、専用プロセスグループを終了して子プロセスの残留・pipe 待ちを防ぐ。ログと設定のアクセス権、ログ descriptor の close-on-exec を確認。依存のパッケージ manifest とビルドプラグインを読み、バージョン・revision・公開日時を固定した。GitHub Actions は追加していない。

## 未検証の環境・制約

- Intel Mac、macOS 26 実機、複数ディスプレイの物理的な抜き差し。

- Developer ID 署名、公証、自動更新、Windows 設定ファイルからの移行は含まない。

公開物へユーザーの接続先・Tailscale ピア一覧・ランタイムログを含めない。
