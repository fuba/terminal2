# 入力・接続パネル・外観の改修

2026-10-31 JST。ユーザーの5項目の指示に対応。

## 変更

1. タブ移動の既定値を ⌘← / ⌘→ に変更。F11 はアプリ操作に割り当てず、高さを合わせる機能はメニューに残した。アプリ操作・タブ番号・検索・端末へ送る Alt＋矢印・グローバルホットキーを設定から記録・変更・解除できる。設定 JSON とメニュー・タブの表示を同期する。重複するキーは再割り当て時に以前の操作から外し、グローバルホットキーの再有効化時にも競合を解消する。
2. 本体の fullSizeContentView と HSplitView を廃止。タイトルバーの下に端末コンテンツだけを置き、接続一覧は外側に連結する独立した NSPanel とした。端末と接続パネルの描画面が混ざらない。通常は本体サイズを維持し、画面端や全幅ウィンドウでは別パネルとの重なりを避けて配置する。外枠の位置は最初から確定し、開く際のスライドはクリップした内側だけで行う。Reduce Motion に従い、画面ロックでアニメーションが止まっても外枠は端末と交差しない。
3. 接続パネルの順序はお気に入り → SSH → Tailscale → ブックマーク → シェル。行の最小高さを24 ptにし、List の大きな自動余白を廃止。シェルは zsh / bash を初期一覧にし、メニュー・実行ファイルの選択・設定画面から追加と削除ができる。
4. Option＋左右は `ESC [ 1 ; 3 D` / `ESC [ 1 ; 3 C` を実 PTY に送る。SwiftTerm v1.99.1 の Meta＋左右が送っていた Emacs の単語移動（ESC b / ESC f）とは分けた。一般の Option→Meta 設定に依存せず、IME の変換中には入力を奪わない。tmux の既存の M-Left / M-Right バインドへ届く。tmux 側の設定は変更しない。
5. フォント名の手入力を macOS 標準 NSFontPanel / NSFontManager に置き換え。ファミリー・フェイス・サイズの変更を適用・保存する。ダーク、ライト、ミッドナイト、ペーパー、モノクロの5配色を追加し、文字・背景・ANSI 16色を一緒に切り替える。既存のカスタム色も維持できる。

## 自動検証

`scripts/test.sh` は29テスト成功（TerminalCore 15、TerminalApp 14）。既存の実 PTY・loopback SSH/SFTP テストを維持したうえで次を追加。

- 旧設定ファイルから新しい既定キーと zsh / bash 一覧への移行。
- キー変更・無効化・JSON 保存、重複の拒否と再割り当て、グローバルホットキーの競合解消。
- 端末・検索・設定画面の入力コンテキスト分離。F11 の非割り当て。
- キー記録で Escape と Command キーを通常の割り当てとして受け取り、アプリ操作を実行しないこと。
- 配色の変更がフォント・不透明度など他の設定を変えないこと。
- 実 NSWindow に fullSizeContentView がなく、接続パネルが独立した子ウィンドウであること。
- 通常の位置・画面端・全幅のウィンドウで、接続パネルとの交差がなく画面内に収まること。
- 実 PTY 上の Python で受信バイトを照合し、Option＋左右が xterm の Alt-arrow 列として届くこと。
- 割り込み操作を別のキーに再割り当てしても、実 PTY へそのキーの文字ではなく Ctrl-C のバイトが届くこと。
- 一時ソケットの実 tmux 3.8 サーバーに2セッションを作り、実 PTY のクライアントから Option＋左右で one → two → one と移動すること。ユーザーの tmux サーバー・設定は変更しない。

## 実画面

通常版とは別の bundle ID と `TERMINAL2_CONFIG` を使い、private な一時設定ファイルで実アプリを起動。実シェル、実 SSH 設定、実 Tailscale の候補を使い、通常版の設定やセッションを変更せず確認した。

- 本体に端末だけがあり、接続パネルが左外側に開くこと、SSH / Tailscale が先頭にあり、シェルが zsh / bash のみで末尾にあること。
- ⌘←で元のタブの出力へ戻れること、⌘→で別のタブへ移動できること。
- 設定のレコーダーで「次のタブ」に ⌘Q を割り当てても記録中に終了せず、終了操作の旧割り当てが解除されること。保存後に ⌘Q が実際のタブ移動になること。一時設定の JSON も照合した。
- macOS 標準フォントパネルから BIZ UDGothic を選択し、サイズを24 ptへ変更。設定画面と JSON のファミリー・サイズ、端末の実際の文字と行列が追従した。
- ライトのプリセットへ切り替え、文字・背景・赤/緑の ANSI 出力・本体の明暗が反映された。

フォントパネルのサイズ欄は AX の値設定だけでは action が確定しなかったため、実際に欄へ入力して Return で確定する経路で検証した。途中で実 SSH ホストの初回確認が出た接続は中止し、ホスト鍵の承認や known_hosts の変更は行っていない。

最終段階で Mac が自動ロックされ、追加の実画面操作は停止した。上記の実画面確認はロック前に実施済み。リリースビルド、署名検査、通常配置先への更新、Git の確認はロックと独立して行う。

### ロック解除後の追加確認

同日、ユーザーのロック解除後に v0.1.0 の公開 ZIP を使って追加確認した。ZIP の SHA-256 を照合し、別 bundle ID と一時設定ファイルを使う検証用アプリを作成した。署名メタデータの変更前後で Mach-O の `__TEXT,__text` セクションが一致することも確認している。

- ビルド `20261030191413` が実際に起動し、Metal の端末表示と実シェルのコマンド実行が動作した。
- 接続パネルが本体の外側に独立して開き、クリップした内側の表示が正常に現れた。本体の本文・タイトルバーとの混在は見られなかった。
- 接続先の順序・行密度・末尾の zsh / bash の一覧を確認した。
- 外観設定で標準フォントパネルの入口・配色選択を確認し、キー割り当て画面で Cmd＋左右、Option＋左右、高さを合わせる操作の未割り当てを確認した。

通常版では旧ビルドの SSH セッションが使われていたため、そのプロセスと設定には触れていない。検証用アプリだけを終了した。通常版へ新 UI を反映するには、セッションを終了できるタイミングで旧版を終了し、更新済みの `~/Applications/Terminal2.app` を起動する。

## レビュー

キーバインドは設定・イベントルーティング・ネイティブメニューで同じ定義を使う。記録中はローカル操作を実行せず、アプリ自身のグローバルホットキーも一時解除する。OS の保護や他アプリのショートカット設定には手を加えない。SSH の認証・ホスト鍵検証・クリップボード read の拒否は維持する。依存の更新や自動 CI は追加していない。

通常版が起動中でも実行ファイルの inode を上書きせず更新する。起動中のセッションは保持し、UI の反映にはアプリの再起動が必要になる。
